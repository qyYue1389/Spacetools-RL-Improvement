## 摘要

**头条:`Eq. 4` 与 `Eq. 5/6` 的归一化不一致,会在 `π_old` 刚离开 `π_ref` 时就把
组内的奖励差异整个抹掉 —— 而阈值小到只有每 token 约 `5e-4` nat。**

    g_i = C − d_i/|y_i| − β·r_i ,   C = mean_j( β·r_j + d_j )
          ^^^^^^^^ 已归一化          ^^^^^^^ 未归一化(Eq. 4)

漂移项在 `C` 里是**求和量级**、在被减项里是**每 token 量级**,于是它在组内近似是一个
**公共平移**。公共平移一旦超过 clip 半宽,整组被推到同一侧,`g̃_i` 全组同值,
**奖励的贡献被完全抹掉**。

| 每 token 漂移 | `C` 的漂移贡献(中位) | **整组 `g̃` 同值** |
|---|--:|--:|
| 0 | 0.0000 | 56.9%(即步骤 2 的奖励简并组,数值吻合) |
| 3e-4 | 0.118 | 10.6% |
| 1e-3 | 0.369 | **36.0%** |
| 3e-3 | 1.228 | **56.0%** |
| 1e-2 | 3.776 | **78.3%** |

阈值可以直接算:`C` 的漂移贡献 sd ≈ 每token漂移 × `|y|` / `√G`,
令它等于 `ε_high = 0.28` 得 **每 token 漂移 ≈ 5.0e-4 nat**(`robospatial`,`|y|≈1258`)
/ **7.5e-4**(`boppose`,`|y|≈839`)。

**而且这条是可修的:把 `Eq. 4` 的 logprob 项也按 `|y|` 归一化,现象完全消失**(§6)。
所以机制的来源是**归一化不一致本身,不是 GFlowRL 的批内估计思路**。

## 1. ⚠ 先更正一个说法:「三种估计法」太松

TB 残差 `Δ_i = C + (1/|y_i|)·log(π/π_ref) − β·r_i`,三者的关系其实是:

| | 常数怎么定 | 用哪个 π | 走不走梯度 |
|---|---|---|---|
| **GFlowRL**(Eq. 4) | 算术平均 | `π_old` | **`sg[]`,不走** |
| **VarGrad** | 使 `Σ Δ_i²` 最小 = 算术平均 | `π_θ` | **走** |
| **DevGrad**(f-TB) | 使 `(1/B) Σ L_f(Δ_i + C)` 最小 | — | — |

**平方损失 + `π_θ = π_old` 时,三者数值上完全相同。** 差别只有两处:
**(a)** 常数里走不走梯度(只在 minibatch 内 `π_θ` 漂开后显形,§5);
**(b)** `f` 的选择 —— 平方给均值、绝对值给中位、Huber 给稳健常数(§4)。

上一轮我说的「同一个常数的三种估计」不够准确,按此更正。

## 2. β × 漂移 的二维扫描(`robospatial`)

格式:**饱和率 / 符号不一致率**(mean vs huber,clip 之后)

| 每 token 漂移 | β=0.5 | β=1 | β=2 | β=8 |
|---|---|---|---|---|
| **0** | 12.3% / 0.0% | 23.5% / 0.0% | 43.1% / 0.0% | 43.1% / 0.0% |
| 3e-4 | 25.7% / 10.9% | 35.8% / 10.2% | 47.5% / 11.0% | 50.0% / 11.3% |
| 1e-3 | 69.0% / 16.2% | 71.3% / 14.8% | 74.4% / 15.5% | 80.8% / 16.4% |
| 3e-3 | 86.2% / 20.1% | 87.5% / 20.1% | 88.7% / 19.3% | 89.8% / 18.0% |
| 1e-2 | 97.0% / 18.1% | 96.6% / 18.1% | 95.9% / 17.4% | 97.0% / 17.4% |

**两条都和写脚本前的猜测相反:**

1. **漂移一旦非零,饱和率就与 β 几乎无关地冲向 100%。**
   β 只在 `drift = 0` 那一行说了算 —— 也就是**只在训练的第一步**。
   步骤 2 那条「β 应从 1 附近起步」的建议因此要加一句限定:**它只对第一步成立**,
   之后 β 对饱和的影响被漂移项淹没。
2. **饱和 ≠ 常数的选择无关紧要。** clip 削掉的是**幅度**,活下来的是**符号**,
   而符号仍然取决于 `C`:mean 与 huber 在 **11%–20%** 的 rollout 上给出**相反的更新方向**。
   （上一轮我在脚本里先写下的判词是「饱和之后常数无关紧要」,**数据不同意,已改。**）

## 3. 组内 `g̃` 被削成同一个值 —— 本节是头条

见摘要的表。三点值得单独记:

- **`drift = 0` 那一行的 56.9% 正是步骤 2 的奖励简并组比例**,数值吻合到小数点后一位。
  这是一次意外的内部一致性校验:两个脚本、两条路径,同一个数。
- **曲线非单调**:小漂移(3e-4)反而把简并组的平局打破,同值率先降到 10.6%,
  再随漂移增大爬过原来的水平。所以「同值率低」不等于「信号好」。
- **阈值极小。** clip 半宽只有 0.2–0.28,而 `C` 里装的是**上千个 token 的 logprob 之和**。
  两者量纲差三个数量级,容差自然只有 `5e-4` nat/token 这个级别 ——
  常规 RL 微调在几步之内就会越过它。

## 4. 估计量自身的抽样方差:i-b 的落点在这里

固定真值,重复抽 `G` 个样本 20000 次:

| G | 噪声分布 | Var(mean) | Var(median) | Var(huber) | 相对 mean |
|--:|---|--:|--:|--:|---|
| 5 | 高斯 | 0.1990 | 0.2867 | 0.2696 | median **1.44×** · huber 1.35× |
| 5 | 重尾 t3 | 0.5836 | 0.4112 | 0.3962 | median **0.70×** · huber 0.68× |
| 5 | 二值+噪声(双峰) | 3.4161 | 11.9909 | 11.9013 | median **3.51×** · huber 3.48× |
| 16 | 高斯 | 0.0634 | 0.0913 | 0.0861 | median 1.44× · huber 1.36× |
| 16 | 重尾 t3 | 0.1829 | 0.1121 | 0.1075 | median **0.61×** · huber 0.59× |
| 16 | 二值+噪声(双峰) | 1.0688 | 7.9345 | 7.9020 | median **7.42×** · huber 7.39× |

**三种分布给出三种不同的排序**,而且方向相反:

- **高斯**:mean 最优,稳健常数付 1.35–1.44× 的方差代价。
- **重尾 t3**:mean 最差,median/huber 只要它的 0.59–0.70×。
- **双峰(二值奖励 + 噪声)**:mean **明显最优**,median 差 3.5–7.4× —— 它去追某一个峰。

> **所以判据 i-b 不能在合成数据上关闭。** 该选哪个常数,完全取决于
> `log π_ref − log π_old` 的**真实分布形状**,而那只有前向 pass 能给。
> **这正是 i-b 的落点:前向 pass 拿到真实漂移之后,先看它的分布形状,再判估计量。**
> 一个先验:我们的奖励在两个准确率 benchmark 上接近二值 —— 若漂移项也接近双峰,
> **算术平均反而是三者里最好的那个**,GFlowRL 的选择在我们这里站得住。

## 5. `sg[]` 值不值(GFlowRL 冻结常数,VarGrad 不冻结)

minibatch 内 `π_θ` 继续漂开时,常数会移动多少:

| minibatch 内每 token 漂移 | 常数移动(均值) | 相对 `β·r` 量程(0–8) |
|--:|--:|--:|
| 0.001 | 0.494 | 0.062 |
| 0.003 | 1.505 | 0.188 |
| 0.010 | 5.244 | **0.656** |
| 0.030 | 13.555 | **1.694** |

**移动量与 `|y|` 成正比**(同 §T6 的量纲失配),所以 `sg[]` 冻住的那个常数,
在一个 minibatch 之内可以漂得**比 `β·r` 的整个量程还大**。
这既是 `sg[]` 的理由(不冻的话梯度要穿过一个这么大的量),
也是它的代价(冻住的值可能很快就过时了)。

## 6. 候选修法:把 `Eq. 4` 也做长度归一化

    C_norm = mean_i[ β·r_i + (log π_ref − log π_old)_i / |y_i| ]

| 每 token 漂移 | 原样 Eq. 4:饱和 / 整组同值 | **归一化后:饱和 / 整组同值** |
|--:|---|---|
| 3e-4 | 54.3% / 11.1% | 43.1% / **0.0%** |
| 1e-3 | 79.1% / 36.0% | 43.1% / **0.0%** |
| 3e-3 | 89.4% / 53.7% | 43.1% / **0.0%** |
| 1e-2 | 96.3% / 78.3% | 43.1% / **0.0%** |
| 3e-2 | 99.4% / 92.6% | 43.1% / **0.0%** |

**归一化之后,两个指标都回到 `drift = 0` 的水平,并且不再随漂移增长。**

> 所以 §3 那个「奖励贡献被抹掉」的机制,**来源是 `Eq. 4` 与 `Eq. 5/6` 的归一化不一致本身,
> 不是 GFlowRL 的批内估计思路。**
>
> ⚠ **代价已于 2026-09-02 测出,这条候选不是免费的。** 见下面的 §6.1。
> (原文写「需要用 `p7_fixedpoint.py` 的框架单独测,本轮没做」—— 现在做了。)

### 6.1 不动点代价:修法恢复了不动点,但那个不动点是个点质量

`tools/p7/p7_fix_cost.py`。沿用 `p7_fixedpoint.py` 的小世界(`|Y|=64`,可精确归一化)。

**先把代数写出来。** 零损失(`Eq. 5` 带长度归一化)要求对每个 `y`:

    Z + (1/L_y)(log π_θ,y − log π_ref,y) − β·r_y = 0
    =>  log π_θ,y = log π_ref,y + L_y·(β·r_y − Z) − c(Z),   c(Z) = logsumexp(...)

代回残差得 `residual_i = Z_t − Z − c(Z)/L_i`。`L` 不同时,要它对所有 `i` 为零,
需要 **`c(Z)=0`** 且 **`Z_t=Z`** 同时成立。前者是一元单调方程,**generically 有唯一根** `Z*`;
后者就是「估计量自洽」那一步:

    Eq.4 原样(未归一化)   Z_t = E[β·r] − E[L·β·r] + Z·E[L]              -> 一般 ≠ Z*
    Eq.4 归一化后(修法)   Z_t = E[β·r + (log π_ref − log π_θ)/L] = Z    ✓ **恒等**

**数值验证**(在 `c(Z*)=0` 构造出的那一点上):

| 世界 | `Z*` | 修法的 `\|Z_t−Z*\|` | 论文原样的 `\|Z_t−Z*\|` | 修法 loss | 论文原样 loss |
|---|--:|--:|--:|--:|--:|
| `\|y\|` 331–3142(中位 1572) | 7.765 | **8.9e-16** | 6.355 | **6.9e-34** | 4.04e+01 |
| `\|y\|` 254–445(中位 366,实测量级) | 7.730 | **8.9e-16** | 4.935 | **0.0** | 2.44e+01 |

> 一致性自查:该点上残差是常数 `Z_t − Z*`,所以 loss 应等于 `(Z_t−Z*)²`。
> 实测 `4.935² = 24.35` 对上 `2.435e+01`。**机械对得上。**

**所以存在性问题被修好了。代价在不动点的位置:**

    同质长度扫描(L 相同,一切可解析)
       L        Z*      loss(修法)      熵 H    有效支撑    max p
       1.0   5.34947    7.3e-31        3.0448    21.006   0.1388   <- 与 Prop.B.1 的 beta-tilt 逐位相同
       2.0   6.24797    3.6e-30        2.2283     9.284   0.2285
       5.0   7.11816    3.2e-30        1.2468     3.479   0.4815
      10.0   7.50997    8.6e-36        0.6471     1.910   0.7500
      50.0   7.88858    7.9e-31        0.0038     1.004   0.9996
     334.0   7.97517    0.0            0.0000     1.000   1.0000   <- robospatial 的实测 |y| 中位
      π_ref                            3.8812    48.482   0.0570

**`L = 334`(robospatial 实测中位 token 数)时,不动点是一个点质量:有效支撑 1.000,`max p = 1.000000`。**
**分布匹配退化成奖励最大化 —— 恰恰是 GFlowRL 要避免的东西。**

`L = 1` 那一行与 Prop. B.1 的 `π_ref·exp(β·r)` **逐位相同**(H 3.0448 / 支撑 21.006 / max p 0.138755),
这是机械自查:修法在 `L=1` 时必须退化成 Prop. B.1,它做到了。

### 6.2 与 `P7_STEP23_RESULTS.md` §2.3 收回的那条,不矛盾

§2.3 收回了「有效逆温度 = `L·β`」,理由是**论文原样**下极小点落在 `c ≈ 0.93–1.15` 而不是 `c = L`。
那条**仍然成立**,因为在论文原样下**根本没有零点** —— 极小值是「自洽」与「零残差」
两个不相容条件的折中,自然落在两者之间。

**修法让零点真的存在了,于是 Remark B.4 的 `L·β` 读法在修法之下回来了。**
两条陈述各自成立,适用于不同的目标函数。

### 6.3 净结论:这条修法不是免费的,而且两面来自同一处

| 配置 | 整组 `g̃` 同值 | 自洽零点 | 不动点的 tilt |
|---|---|---|---|
| **A. 论文原样**(Eq.4 不归一化 / Eq.5-6 归一化) | 26.9%–46.0%(实测) | **不存在** | 极小点 `c ≈ 1` |
| **B. §6 修法**(两边都归一化) | **0.0%**(实测) | **存在** | **`L·β` → argmax** |
| **C. 两边都不归一化**(回到 Prop. B.1) | — | 存在 | `β`,熵与 `π_ref` 同量级 |

**A 的病(奖励贡献被抹掉)与 B 的病(不动点塌成 argmax)是同一个长度归一化的两面。**
唯一在两个指标上都健康的是 **C** —— 而 C 的代价正是论文当初引入长度归一化要解决的问题:
长序列在 loss 里权重更大。**论文选了 A,把这个 trade-off 记在 Remark B.4 里称作
「mild length-dependent bias」;实测下来它既不 mild,也不只是 bias。**

## 8. 局限

- **漂移项是合成的。** 本文所有涉及 `drift` 的数字都依赖那个假设(独立高斯 × `|y|`)。
  真实的 `log π_ref − log π_old` 可能有跨 rollout 相关性、可能不对称。
  **前向 pass 之后必须用真值重跑。**
- **长度是字符不是 token**,阈值 `5e-4 nat/token` 的绝对值随之带同样的不确定性;
  量级(1e-4 ~ 1e-3)可信。
- **奖励来自单次采样运行(n=1)**,同前几份文档的标注。
- §6 的候选修法**只测了症状消失,没测代价**(不动点、收敛性)。
- 本文全部在**总体/解析层面**,没有跑真实的梯度步。
